# 🌍 Explore with Pragati

A multi-page AI-inspired travel website designed and deployed using HTML, CSS, and GitHub Pages.

🔗 **Live Demo:**  
https://pragatigupta2508.github.io/Travel_Log/

---

## 📌 Project Overview

**Explore with Pragati** is a responsive travel website that showcases destinations, booking interfaces, and user authentication UI.

The platform is structured with future integration in mind for AI-based travel recommendation systems to deliver personalized destination suggestions based on user preferences.

---

## 🚀 Features

- Multi-page structured website architecture
- Responsive and visually engaging UI
- Destination browsing interface
- Booking form interface
- Signup/Login UI
- HTTPS-enabled live deployment via GitHub Pages
- AI-inspired travel recommendation system (rule-based logic concept)

---

## 🤖 AI Integration (Concept)

The platform includes a blueprint for a rule-based travel recommendation engine that:

- Accepts user preferences (budget, mood, travel type)
- Maps inputs to suitable destinations
- Simulates personalized travel suggestions

### 🔮 Future Scope
- Machine Learning-based recommendation engine
- User preference data modeling
- Dynamic filtering using JSON datasets
- Backend integration for real authentication & data storage
